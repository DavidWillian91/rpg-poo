# RPG: Batalha Mística

Este projeto é um pequeno jogo de RPG em Python, desenvolvido com foco na prática de orientação a objetos (POO). O jogador entra em uma batalha contra um inimigo, podendo escolher entre atacar ou usar poções para sobreviver.

## Funcionalidades
- Criação de personagens com atributos de vida e ataque.
- Sistema de batalha por turnos entre jogador e inimigo.
- Uso estratégico de poções de cura.
- Exemplo prático de herança, encapsulamento e reutilização de código com classes.
